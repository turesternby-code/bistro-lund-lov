# Bistro 13 Site

Create a polished, responsive Swedish website for Bistro 13 in Lund using only the provided information. Important: do NOT generate or use AI images, stock photos, or external photos. Instead, create attractive, clearly labeled image placeholder/upload areas throughout the site where the restaurant can later add its own photos (for example hero photo, food gallery, atmosphere/interior). Use refined typography, warm bistro styling, tasteful colors and layouts so it feels finished even without images. Include: hero with Bistro 13 identity; calls to action for finding directions and viewing menu; service options (uteservering, privat matsal, veganska alternativ); address Sandgatan 10, 223 50 Lund; weekly hours Mon–Sat 10–17 and Sun 11–17; price range 100–200 kr per person; menu preview, about/story, gallery placeholders, contact/location section, and footer. Content must be in Swedish, and site must be mobile responsive. Do not claim live table bookings, ordering integrations, or unsupported details.
